# Apprenticeship Entry Test

This repository contains solutions for an apprenticeship entry test. The test covers logic & problem solving, web development, debugging & reasoning, and version control & collaboration.

## Structure

## Section 1: Logic & Problem Solving 
question1.py: Python function to find the second-largest number in a list.
question2.txt: Written explanation about optimizing slow web pages.
## Section 2: Web Development
Question 3: Frontend
Index.html: Simple profile page structure.
script.js: Fetches and displays user data from an API, with loading and error handling.
Question 4: Backend
totalRevenue.js: JavaScript function to calculate total sales revenue from a dataset.
## Section 3: Debugging & Reasoning
question5.py: Python script for debugging and reasoning tasks, including removing even numbers from a list.
## Section 4: Version Control & Collaboration
question6.txt: Answers about using Git for team collaboration, common commands and resolving merge conflicts.
